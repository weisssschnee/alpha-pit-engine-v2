# Architecture Boundary

Updated: 2026-07-14

## Graph authority

`.planning/architecture/architecture_registry.json` is the sole status and
boundary authority. `.planning/architecture/architecture_graph.json` and
`.planning/architecture/architecture_graph.html` are generated by
`scripts/build_nextgen_dark_architecture_graph.py` from the accepted Phase A
registry and that authority registry.

The builder validates required nodes, implementation/evidence paths, allowed
statuses, mandatory forbidden feedback edges and per-node verification hashes.
The Markdown diagrams are projections, not independent implementation claims.

Raw code-navigation output is maintained separately under
`.planning/codegraph/`. Every snapshot is named with its full repository SHA.
It may contain historical and superseded files and can only describe observed
source structure; it cannot assert research status or data-access authority.

The deprecated `.planning/graphs/graph.*` files are compatibility pointers and
cannot assert state. `stale=false` is valid only when
`scripts/check_architecture_freshness.py` confirms the registry hash, source
repo SHA, generator hash and every declared derived display hash.
